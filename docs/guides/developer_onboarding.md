# Developer Onboarding Guide

## Prerequisites
- Python 3.10+
- Node.js 18+ & npm
- Docker & Docker Compose (optional for local MongoDB)

## Quickstart
1. Clone the repository.
2. Initialize backend virtual environment: `python -m venv venv && pip install -r backend/requirements.txt`.
3. Install frontend dependencies: `cd frontend && npm install`.
4. Start local development cluster.
