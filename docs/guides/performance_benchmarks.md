# Performance Benchmarks

Target latency and throughput specifications for SwasthyaTwin backend analytics.

| Operation | Target Latency (p95) | Target Throughput |
| :--- | :--- | :--- |
| Telemetry Ingestion | < 15 ms | 500 req/sec |
| Twin State Recalibration | < 45 ms | 200 req/sec |
| What-If Simulation Request | < 60 ms | 150 req/sec |
| Full Trajectory Projection | < 100 ms | 100 req/sec |
