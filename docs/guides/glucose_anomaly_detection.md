# Continuous Glucose Monitoring (CGM) Anomaly Detection

## Thresholds & Metrics
- **Time In Range (TIR)**: Goal > 70% (70 - 180 mg/dL).
- **Time Below Range (TBR)**: Goal < 4% (< 70 mg/dL) and < 1% (< 54 mg/dL).
- **Glycemic Variability (CV)**: Coefficient of variation target $\le 36\%$.
- **Acute Spike Detection**: Rate of change $> 3.0\text{ mg/dL/min}$ triggers rapid-rise alert.
