# Clinical Data Dictionary

Comprehensive enumeration of physiological data points collected across the digital twin platform.

### Cardiovascular
- `heart_rate`: Beats per minute (bpm).
- `blood_pressure_systolic`: Peak arterial pressure (mmHg).
- `blood_pressure_diastolic`: Minimum arterial pressure (mmHg).
- `pulse_wave_velocity`: Arterial stiffness surrogate (m/s).

### Metabolic
- `fasting_glucose`: Serum glucose level (mg/dL).
- `hba1c`: Glycated hemoglobin percentage (%).
- `bmi`: Body Mass Index ($kg/m^2$).
