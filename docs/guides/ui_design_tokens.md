# UI Design Tokens & Theme Specification

## Palette Tokens
- **Primary / Brand**: Medical Teal `#0d9488`
- **Cardiovascular Alert**: Coral Red `#ef4444`
- **Metabolic Warning**: Amber `#f59e0b`
- **Optimal Health**: Emerald `#10b981`
- **Surface Dark**: Midnight `#0f172a`
- **Surface Light**: Pure White `#ffffff`

All text contrast ratios exceed WCAG AA standards (minimum 4.5:1).
