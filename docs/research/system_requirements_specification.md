# System Requirements Specification (SRS) - Draft v0.1

## Functional Requirements
- **FR-01**: Ingest continuous physiological vitals within 50ms of receipt.
- **FR-02**: Calculate composite organ health scores across cardiovascular, metabolic, and renal systems.
- **FR-03**: Support real-time parameter perturbation in What-If counterfactual simulator.

## Non-Functional Requirements
- **NFR-01**: System availability $\ge 99.9\%$.
- **NFR-02**: Responsive UI rendering at 60 frames per second on modern web browsers.
