# BiDSleep Wearable Sleep Staging Pipeline Design (July 13, 2026)
## Objective
Evaluate feasibility of 5-stage AASM sleep architecture classification using non-invasive wearable optical PPG telemetry.
- Ground truth: In-lab polysomnography (PSG) 30s hypnograms.
- Target classes: Wake, N1, N2, N3, REM.
