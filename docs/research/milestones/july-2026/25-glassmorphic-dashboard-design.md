# Glassmorphic Digital Twin UI Design System (July 25, 2026)
## Aesthetic Tokens
- Backgrounds: Dark slate gradients (`bg-slate-950`, `bg-slate-900/90`).
- Borders: Subtle glow accents (`border-cyan-500/30`, `border-purple-500/30`).
- Typography: Monospace telemetry accents paired with clean sans-serif typography.
- Micro-animations: Fade-in modals, pulse status badges.
