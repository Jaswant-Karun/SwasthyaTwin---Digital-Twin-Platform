# Five-Tier Data Provenance Model (July 8, 2026)
## Provenance Tiers
1. **`measured`**: Direct physical instrumentation (cuff, sensor, lab).
2. **`derived`**: Deterministic arithmetic aggregation over multiple readings.
3. **`model_predicted`**: Statistical or supervised machine learning inference (BiDSleep).
4. **`simulated`**: Counterfactual twin projections under intervention parameters.
5. **`synthetic`**: In silico test fixtures; strictly isolated from patient records.
