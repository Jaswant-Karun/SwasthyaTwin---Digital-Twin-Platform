# Wearable Optical Photoplethysmography Protocol (July 3, 2026)
## Principles
Photoplethysmography (PPG) captures volumetric changes in microvascular tissue beds.
- Green wavelength (525 nm) for superficial capillary perfusion.
- Infrared wavelength (940 nm) for deeper tissue penetration.
- Filtering: 0.5–5.0 Hz bandpass Butterworth filter to isolate pulse waveforms from motion artifacts.
