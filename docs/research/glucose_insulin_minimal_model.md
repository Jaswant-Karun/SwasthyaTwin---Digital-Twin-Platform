# Glucose-Insulin Dynamics & Bergman Minimal Model Adaptations

## Theoretical Foundation
The Bergman Minimal Model describes plasma glucose $G(t)$ and insulin action $X(t)$ dynamics:

$$\frac{dG}{dt} = -(p_1 + X(t))G(t) + p_1 G_b$$
$$\frac{dX}{dt} = -p_2 X(t) + p_3 (I(t) - I_b)$$

We parameterize a surrogate polynomial approximation to enable real-time what-if simulation on standard consumer hardware.
