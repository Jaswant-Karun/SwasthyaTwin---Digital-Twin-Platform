# SwasthyaTwin Backend Service

High-performance asynchronous Python backend built with FastAPI, Motor (async MongoDB driver), and Scikit-learn analytics engines.

## Key Packages
- `app.api`: REST API router definitions and request/response models.
- `app.analytics`: Machine learning models, risk scoring calculators, and what-if simulation logic.
- `app.database`: Async MongoDB client connection management and index declarations.
- `app.models`: Pydantic domain entities and validation rules.
- `app.services`: Business orchestration and digital twin state synchronization.
