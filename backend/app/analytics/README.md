# Analytics & ML Module

Core analytical machinery powering the SwasthyaTwin platform.

## Submodules
- `rule_engine.py`: Deterministic clinical rule evaluation for triage and alerts.
- `models_store/`: Serialized pre-trained estimators, scalers, and dimensionality reduction matrices.
- `risk_calculator.py`: Composite organ health score aggregation.
- `simulator.py`: What-if parameter perturbation logic.
