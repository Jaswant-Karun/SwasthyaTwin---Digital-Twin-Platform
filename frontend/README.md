# SwasthyaTwin Frontend Web Application

Modern React 18 single-page application built with TypeScript, Vite, and Lucide icons for clinical data visualization.

## Architecture Highlights
- **Atomic Component Hierarchy**: Reusable cards, badges, modal dialogs, and trajectory charts.
- **Twin Context Provider**: Reactive state management synchronizing active patient profiles.
- **Interactive Simulator**: Real-time slider perturbations computing delta outcomes client-side and server-side.
